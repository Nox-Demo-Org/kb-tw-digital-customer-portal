# Components and data models

One page per significant component and core data model.

## Pages

- [Billing Plan](/entities/billing-plan.md) — The Billing Plan entity represents a policyholder's payment schedule and instalment fee metadata fetched from the upstream billing-service.
- [Claim](/entities/claim.md) — The Claim entity represents an insurance claim within the customer-portal application.
- [Policy](/entities/policy.md) — The Policy entity representation in the customer-portal provides customers with a read-only self-service view of their insurance policies retrieved from the upstream policy-admin microservice.
